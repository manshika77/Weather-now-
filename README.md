# WeatherNow 🌦️

A responsive weather application built with HTML, CSS and JavaScript.

## Features

- Search weather by city
- Temperature
- Weather condition
- Humidity
- Wind speed
- Feels-like temperature
- Responsive design
- OpenWeather API integration
- Demo mode without an API key

## How to run

1. Download or extract the project.
2. Open `index.html` in your browser.
3. Try searching for New Delhi, Mumbai or Bangalore.

## Enable live weather

1. Create an OpenWeather API account.
2. Get an API key.
3. Open `script.js`.
4. Put your key inside:

```js
const API_KEY = "your_api_key_here";
```

5. Save and refresh the app.

## Technologies

- HTML5
- CSS3
- JavaScript
- Fetch API
- REST API

## Portfolio description

WeatherNow is a responsive weather application developed using HTML, CSS and JavaScript. It uses the Fetch API to retrieve weather information and dynamically updates the interface based on the selected city.
